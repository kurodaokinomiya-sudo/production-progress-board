# 注文をまとめて確認・反映する

PDF・画像・メール本文の貼り付けで取り込んだ後、「取込内容を確認」画面の「まとめて確認・編集」を押します。

全品目の得意先・品名・数量・納期・連番・大分類・全長・型・刃幅・備考を、その場で編集できます。「読取元を確認」で元の読取テキストも表示できます。

最初はすべて選択されています。今回は反映しない品目のチェックを外して、「N件を案件へ反映」を押してください。選択を外した品目は確認待ちに残ります。1回に反映できるのは100件までです。

不要な品目は各行の「削除」、複数まとめる場合はチェックを付けて「選択したN件を削除」を押します。「すべて選択」で全選択・全解除できます。確認表示で件数を確認し「削除する」を押すと、取込キューから外れます。チェックを外した行も、その行の「削除」から個別に削除できます。個別の確認・編集画面にも「この品目を削除」があります。

削除は必須項目が空欄でも実行できます。削除した候補は画面から元に戻せませんが、シートの行を物理削除せず、除外状態と操作履歴を保存します。すでに案件へ反映された候補は削除できません。100件を超える全選択は100件ずつ順に処理します。途中で失敗した場合は削除できた品目だけを外し、未完了の品目と編集内容を残します。通信が途切れた場合も、残った品目から再試行できます。

得意先・品名・数量は必須です。数量は1〜1,000,000の整数です。入力に不足・誤りがある場合、選択中の注文はまだ登録せず、修正箇所を表示します。読み取り値は原本と照合してください。

反映した案件は未着手となり、ラベルも印刷待ちに入ります。途中の保存に失敗した場合は成功した品目だけ一覧から外し、未完了の品目を残します。通信が途切れて結果が不明な場合は、同じ画面から再試行できます。同じ確認候補からの二重登録を防ぎます。原本を新たに取り込み直す操作は別候補になるため、この再試行とは異なります。

編集内容はダイアログを閉じても同じページ内で保持します。再読込・タブを閉じる操作では未反映の編集を破棄します。他の端末へ編集途中の内容は同期しません。案件へ反映したデータが同期対象です。

表示は既存のHallmarkデザイン規約とトークンを継承し、PCは横並びの編集行、タブレット以下は折り返し表示にしています。一括反映の機能確認は `tools/bulk-intake-qa.mjs`、削除・キャンセル・通信切断後の再試行の確認は `tools/intake-delete-qa.mjs`、保存処理の検証は `tests/bulk-intake.test.mjs` です。
