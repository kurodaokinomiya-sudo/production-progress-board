# メール本文をコピーして取り込む

1. 「注文を取り込む」→「本文を貼り付け」を開きます。
2. メールから件名（任意）と本文をコピーして貼り付けます。クリップボードの読取許可やGmailへの接続は不要です。
3. 初期設定の「AIを使わず読み取る」で「本文を読み取る」を押します。AIを使いたい場合だけ読取方法を切り替えてください。AIの設定・上限は既存のものを使います。
4. 確認待ちの各候補を開き、原文と全品目・数量・納期・仕様を照合してから「確認して案件へ反映」を押します。反映した案件は印刷待ちになります。

読み取れない書式では、次のように項目名を付けて整えてください。複数品目は品名からのまとまりを繰り返します。

```text
得意先: 田中
品名: ケリソン18cm上向3mm
数量: 10
納期: 2026-11-30
連番: 26-1790-1

品名: 鋭匙鉗子21cm直4mm
数量: 5
納期: 2026-11-30
連番: 26-1790-2
```

本文は30,000文字までです。表の列が崩れた文章や省略の多いメールは、AIなしで全明細を正確に読めるとは限りません。抜けた品目や数量がないか必ず確認してください。数量不明は空欄となり、1以上の整数を入力するまで案件に反映できません。

同じ件名を再度読み込んでも以前の候補は消しません。同じメールを繰り返し取り込むと重複候補ができるため、不要な候補は「今回は使わない」にしてください。

取込エラーでは本文を画面に残します。ページの再読み込み・終了をすると未送信の本文は失われます。AIなしでも、公開版では貼り付けた本文をこのアプリのApps Scriptへ送信し、確認用原文としてスプレッドシートに保存します。AIを選ぶとGoogleのAIサービスへも送信します。
