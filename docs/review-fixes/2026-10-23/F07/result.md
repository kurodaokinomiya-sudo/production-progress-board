# F07 再現可能なブラウザーQA

個人のPlaywright/Chrome絶対パスを9本の既存QAで確認し、共通ランタイムへ移した。Playwright 1.64.1を正確な開発依存・package-lockへ固定した。既存シナリオは削除していない。

既定は `npm ci` → `npm run qa:install` → `npm run qa`。専用サーバーを空きポートで起動し、隔離contextを使う。外部URLを拒否し、QAモードのサーバーはAI・認証ファイル・本番プロジェクト情報を拒否する。結果JSON/trace/失敗PNGを残し、失敗は非0で終了する。詳細は `docs/browser-qa.md`。

検証:

- ソース版・生成物の主要画面、注文・工程の編集/保存/再読込、768px表示の既定スモーク成功。
- 空きポート、HTTP起動確認、ポート競合、起動ファイル不在、起動タイムアウト、Chromium未導入、意図した検証失敗、外部URL拒否、AI/認証ファイル拒否を実行して終了結果・成果物を確認。
- 既存project-link QA成功（合成プロジェクト/外部遷移はmock、320/768/1280px）。
- 既存研磨QAは現行の完了操作の非表示と楽観表示に合わせ、全数戻り前の完了操作禁止・実保存完了待機へ修正し、成功した。発送/全数戻り/最終仕上げ/取消の範囲を維持する。
- 関連23テストと9本の構文確認成功。個人ホーム/Codexランタイム/個人Chromeパスの参照が残っていないことを確認。

残る範囲: 既定スモークと上記代表QA以外の旧シナリオは、この項目では全件再実行していない。旧シナリオの成功を一括で主張しない。生成物もローカルMockApiであり、GAS・Sheets・Google認証・本番との差は未検証。
