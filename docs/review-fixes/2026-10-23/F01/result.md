# F01 共有ロック

現状の指摘を確認し、`withDocumentLock_` を全入口で同じScriptLockへ変更した。既存名は呼出元との互換のため維持する。
AccessControlも同じScriptLockを使用しており、両ヘルパーを入れ子で呼ぶ経路はなかった。既存の確認メール送信をロック解放後へ移し、共有データの保存をメール待ちで占有しないようにした。AI通信・Gmail検索の範囲は広げていない。

関連152テスト成功。nullのDocumentLock、別実行・認証入口との排他、取得失敗時の書込禁止、例外解放、version競合、既存の在庫・工程・取込の回帰を確認した。

Google公式仕様: https://developers.google.com/apps-script/reference/lock/lock-service

実GASの同時実行は未検証。後日許可されたテスト用コピーに配置し、Webアプリの二端末・管理入口・トリガーから同じ案件/在庫を同時更新する。片方の古いversionが拒否され、在庫/取込が重複せず、例外後に次の保存が通ることを確認する。
今回のスタブは実行間の排他を模擬するもので、GASの実スケジューリング・待機時間を再現しない。
